# 双人星轨 · Our Orbit

一个属于两个人的小空间：深空粒子背景 + 三个小游戏 + 一份「一起要做的事」清单。
纯前端单页，零依赖、零后端，数据存在浏览器 localStorage 里。

网站：https://baige070130.github.io/stardust-radio/

## 功能

### 🎁 每日默契盲盒
每天一题（60 题轮换）。两个人各写一遍答案，点「一起开盒」才揭晓，
并给出 0–100 的默契指数（按两人回答的字面重合度计算）。往期开盒记录会留档，连续天数自动统计。

### ✒️ 故事接力
一人一句往下接，轮次自动交替（屏幕会提示轮到谁）。
故事随时可以「到这里就结束」，成品会保留在页面上。

### 🍜 今晚吃啥
可增删改的决策转盘，物理感缓动旋转，停在哪个就吃哪个。

### 📌 一起要做的事
完整的增删改查：添加（标题 / 分类 / 备注）、勾选完成、行内编辑、删除、按状态筛选、
进度条、以及「随机抽一件」帮你决定今天做哪件。

### ⚙️ 设置
- 改两个人名字、设置在一起纪念日（顶部显示「第 N 天」）
- 「复制分享码」把全部数据压成一个 base64 串，发给对方用「导入」即可同步
- 清空数据

## 技术

- 原生 HTML / CSS / JS，无框架、无构建、无 CDN
- Canvas 2D 粒子星尘背景，鼠标划过会被推开再回流，操作成功时从元素位置放一束粒子
- 全部状态存 `localStorage`（键名 `our-orbit-v1`），换设备用分享码迁移
- 响应式，手机可正常使用；尊重 `prefers-reduced-motion`
